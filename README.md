# User Registration Form

A simple user registration form built using HTML, CSS, and JavaScript.  
This project demonstrates client-side form validation with a clean and accessible user interface.

---

## Project Description

This project is a basic user registration page where users can enter a username, email address, and password.  
The form validates user input on submission and provides clear error messages for invalid fields.

It is designed to practice form handling, validation logic, and UI styling without using any external libraries or frameworks.

---

## Features

- User-friendly registration form
- Client-side form validation
- Error messages for invalid inputs
- Success message on valid submission
- Accessible form elements using ARIA attributes
- Responsive and clean design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run the Project

1. Open the project folder
2. Open `index.html` in any modern web browser
3. Fill in the form fields and submit to see validation in action

---

## Validation Rules

- Username cannot be empty
- Email must follow a valid email format
- Password must contain at least 6 characters
